# Portfolio content drafts

새 포트폴리오 홈페이지 제작에 사용할 문구입니다. 작성자의 원문과 문체를 유지하고, 명확한 오탈자·띄어쓰기·조사 오류만 수정했습니다.

- `about.md`: 소개, 학력, 전시 이력, 연락처
- `tuk-tak-tok.md`: 몰입형 인터랙티브 설치 프로젝트
- `tarot-card.md`: 기존 타로 카드 프로젝트
- `tarot-card-with-ai.md`: 생성형 AI를 활용한 타로 카드 프로젝트
- `refresh-too-much.md`: 전시 도록 편집 디자인 프로젝트

`tarot-card.md`와 `tarot-card-with-ai.md`는 최종 홈페이지에서 하나의 프로젝트 페이지로 통합할 예정입니다.

## 게시 전 확인 사항

- 원문에 적힌 `Daegu Art Deyssdey 2026`의 공식 영문 표기와 2026년 12월 전시 일정을 최종 확인해야 합니다.
- 연락처는 공개 저장소와 홈페이지에 노출되는 정보입니다.
